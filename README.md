# 🚀 Local Talent, Global Stage (TalentOrbit)

> **“Discover Talent. Create Opportunities. Reach the Global Stage.”**  
> *“Talent should not remain hidden because opportunity was unavailable.”*

---

## 🌟 The Core Hackathon Story
Instead of being just another social platform or portfolio viewer, **Local Talent, Global Stage** is **a digital bridge between hidden grassroots talent and global opportunities**.

### The 7-Step Core Loop:
```
DISCOVER  ➔  VERIFY  ➔  SHOWCASE  ➔  MATCH  ➔  CONNECT  ➔  OPPORTUNITY  ➔  GROW
```

---

## ✨ Features Implemented (Aligned with Prompt Specifications)

### 1. Landing / Welcome Page
- **Hero & Branding**: Centered logo, glowing ambient styling, tagline, and mission statement.
- **Animated Statistics Counters**:
  - `50,000+` Talents Discovered
  - `10,000+` Opportunities
  - `2,500+` Organizations
  - `5,000+` Competitions
  - `100+` Cities Connected
- **Who Can Join?**: Three dedicated user pathways:
  1. *Talent / Professional* (Artists, freelancers, students, innovators)
  2. *Recruiter / Opportunity Provider* (Companies, studios, enterprises)
  3. *Organizer / Community Builder* (Festival curators, hackathon directors)
- **How It Works**: 6-step interactive visual roadmap.
- **Demo Support Helpline Desk**:
  - Talent Support: `1800-825-3681`
  - Recruiter Support: `1800-825-3682`
  - Organizer Support: `1800-825-3683`
- **Bottom CTA & Footer**: "Your Talent Deserves a Stage" with links and 2026 copyright.

### 2. Sign-Up & Phone OTP Verification Flow
- **Step 1**: Phone number input with country code selector + **Realistic 6-box OTP verification** with resend timer.
- **Step 2**: Account creation with real-time **Password Strength Indicator** (Weak, Medium, Strong).
- **Step 3**: Friendly Role Selection:
  - *"I Want to Showcase My Talent"*
  - *"I Want to Discover & Hire Talent"*
  - *"I Want to Create Opportunities"*

### 3. Login & Instant Persona Access
- Username/password authentication with password visibility toggle.
- Forgot password simulated OTP dispatch.
- **Instant Demo / Judge Logins**: 1-click evaluation buttons for Talent Mode, Recruiter Mode, and Organizer Mode.

### 4. AI-Powered Profile Creation (3-Step Wizard)
- **Step 1: Personal Details**: Name, location (Guntur, Vijayawada, Hyderabad, Chennai, Vizag, etc.), age, category, profession, experience, availability, salary, languages.
- **Step 2: Achievements**: Awards, certifications, competitions participated & won, projects.
  - **Embedded AI Bio Generator**: Automatically writes an elite, tailored summary in 1-click.
  - **Embedded AI Skill Recommender**: Recommends in-demand complementary skills.
- **Step 3: Media Showcase**: Upload simulated proof of work (Audio, Video, Images, Certifications, Code projects).

### 5. Main Home Dashboard & Talent Discovery
- **Hero Search Bar**: Natural language search with chips (`Graphic designers`, `Classical dancers`, `Software developers`, `Singers`, etc.).
- **Rich Multi-Filter Drawer**: Filter by city, min experience, availability, and verified-only toggle.
- **16 Interactive Category Badges**: Art & Design, Music, Dance, Film, Tech, Photography, Writing, Sports, Science, Trades, Gaming, etc.
- **Curated Feeds**: "All Talents", "Rising Talent", "Top Rated Talent", "Talent Near You".

### 6. Interactive Creator Portfolio (Profile Modal)
- Professional portfolio with banner, verified badges, and metrics.
- **Interactive Community Endorsements**: Users can click `+1 Endorse` on specific skills.
- Tabbed history: Portfolio Media Showcase, Experience Timeline, Awards Record, Verified Endorsements.

### 7. AI Talent Match Engine (Recruiter Innovation)
- Recruiters enter natural language prompts (e.g. *“I need a graphic designer with 2 years experience who can work remotely”*).
- System computes compatibility scores (`94% Match`, `88% Match`, etc.) with full breakdown:
  - Skill Match %
  - Experience Match %
  - Location Match %
  - Availability Match %
- Displays detailed **"Why AI Recommended This Candidate"** rationale card.

### 8. Competitions & Festivals Section
- Cards with registration deadlines, prize money (e.g., `₹2,50,000`), mode (`Online / Offline / Hybrid`), and participant counts.
- Interactive **1-click Registration** flow.
- Organizer **"+ Create Competition"** modal with poster upload simulation, rules, and contact info.

### 9. Opportunities & Jobs Board
- Openings from Zenith Labs, Veloce AI, Svara Records, AeroMarine CleanTech.
- Real-time application submission with custom cover notes and attached verified profile.
- Recruiter **"+ Post Opportunity"** modal.

### 10. Recruiter Dashboard & Hiring Funnel
- Real-time metrics: Active Jobs, Applications (45), Shortlisted, Interviews (8), Offers Sent (3).
- Instant candidate search with shortlist toggle and direct personalized offer message dispatcher.

### 11. Cross-Discipline Collaboration System
- Browse by role: Filmmakers searching for actors/editors, Startups looking for developers/designers.
- Request tracking: Pending, Accepted, Rejected with instant response actions.

### 12. Direct Messaging & Notifications Center
- Real-time notification drawer with unread counters.
- Interactive messaging with **simulated intelligent auto-replies** and attachment sharing (Share Profile, Share Job, Share Fest).

### 13. Settings & Theme Support
- Account info, Appearance (Dark/Light mode), notification toggles, privacy visibility, security, and demo helpline contacts.

### 14. 🎯 Hackathon Judge Demo Tour Bar
- Floating tour pill that guides judges through the **10 core hackathon evaluation steps** in under 2 minutes with 1-click step jumps!

## 🛠️ Tech Stack
- **Frontend**: React 19 + Vite 8
- **Styling**: Tailwind CSS v4 + Custom Glassmorphism & Micro-animations
- **Icons**: Lucide React
- **Celebration Effects**: Canvas Confetti

```bash
# 2. Start development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.
